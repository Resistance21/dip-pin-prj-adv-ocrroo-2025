## User Stories

## Story one

As a student, I want to change the presentation of the text in the OCR transcript, I want to be able to change the font size, font colour and background of the text area, to make reading the out text easier.

## Story two

As a learner using the OCR, I want to know when the OCR is processing my request so that I know it is working, this is so that I don’t keep requesting new OCR outputs when I think it is not working when response times are slower than normal.

## Story Three

As a learner that has to use the OCR multiple times, I want to be able to see when the last OCR request was made, so that I know if I have already requested an OCR on the current video frame.
