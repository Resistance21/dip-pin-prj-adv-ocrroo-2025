# Persona: Sam Heron

## Profile

- **Name:** Sam Heron
- **Age:** 25
- **Gender:** Male
- **Tech proficiency:** Above beginner programmer; comfortable with everyday computer use
- **Primary device:** Desktop PC, with occasional laptop use

## Background

Sam is 25-year-old male who has tried to learn programming when they were younger, but they started to have problems with their vision. Once their vision worsened it became too difficult to focus on learning programming. Now that Sam has become better at handling their life with bad vision and the tools, he has access to, he has decided to try learning programming again.
Since a lot of coding is now in the form of video tutorials, Sam finds it hard to read the text in some videos, he would like to find a tool that could help with this problem.

Sam is comfortable with his tech level in that he can comfortably use a computer and the devices he has access to. He would consider himself an above beginner level programmer.
He understands the basics, but it is hard to get much higher on his own.
He currently uses an on-screen magnifying glass for text when he needs it, but the magnifier can have problems with video frames.
Sam mainly uses a desktop PC when working, with some laptop use if needed.

## Goals

- Become proficient in programming languages like Python
- Become a professional programmer so he can make a living off programming
- Able to comfortably use video tutorials for programming without needing to use auto caption generation for text.

## Pain Points

- Learning from video programming tutorials can be very difficult if the video has small font, lower quality video or lower contrasting colours.
- Auto caption generation for videos can be very hit or miss with nearly all videos having problems with reading text.
- Learning for video tutorials can triple the time it takes to learn from a well written tutorial, but it is becoming less common for full written tutorials over video.
- Most transcribe sites do not allow for customisation of the output text, Sam would like to be able to modify the output text for when it is hard to read.

## Relevant issue

[Relevant issue on GitHub](https://github.com/Resistance21/dip-pin-prj-adv-ocrroo-2025/issues/1)

This issue is relevant to on of the persona pain points as it directly addresses this pain point,

“Most transcribe sites do not allow for customisation of the output text, Sam would like to be able to modify the output text for when it is hard to read.”

As this issue states,

“As a student, I want to change the presentation of the text in the OCR transcript, I want to be able to change the font size, font colour and background of the text area, to make reading the out text easier.”

And has an acceptance criteria of,

- Settings panel renders adjacent to the transcript text area
- Font size input accepts numeric values within a sensible range
- Text and background colour pickers update the textarea live
- Settings state is shared between the panel and the OCR output component

Which will fix this pain point or at lest reduce it.
